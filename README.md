# 🔥 Firewall Rule Management System (Real-Time Monitoring)

A complete cybersecurity project with firewall control, real-time traffic monitoring,
and automatic DDoS detection.

## 🚀 Features
- Manual firewall GUI (Allow / Block Ports & IPs)
- Real-time traffic monitoring (GUI)
- Automatic DDoS detection & IP blocking
- Logging (traffic & firewall actions)

## 🛠️ Technologies
- Python 3
- Linux (Ubuntu / Kali)
- UFW
- Tkinter
- Raw socket programming


## ▶️ How to Run

⚠️ Run on Linux (Ubuntu / Kali)  
⚠️ Use sudo permissions

### 1️⃣ Enable Firewall (One time)
sudo ufw enable

2️⃣ Start Traffic Sniffer (Background)
sudo python3 traffic_sniffer.py

3️⃣ Start Web Dashboard (New Terminal)
sudo python3 app.py

4️⃣ Open Browser
http://localhost:5000
